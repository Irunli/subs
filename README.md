# Подписки

Простой трекер подписок для iPhone в стиле Liquid Glass. Сколько уходит в месяц, что спишется дальше, сколько осталось заплатить до конца месяца. Без лимита на количество подписок, без регистрации и рекламы.

**Открыть:** [irunli.github.io/subs](https://irunli.github.io/subs/)

## Что умеет

- **Скоро** — ближайшее списание крупно, сколько осталось заплатить в этом месяце и список по месяцам с суммой за каждый. Если до списания меньше недели, вместо даты будет «Через 3 дня».
- **Подписки** — сумма в месяц и в год, раскладка по категориям, сортировка по дате или цене.
- **Календарь** — все списания месяца по дням, открывается тапом по карточке месяца.
- Оплата раз в неделю, месяц, 3 месяца, полгода или год. Подписку можно поставить на паузу, тогда она не учитывается в суммах.
- Разные валюты (IDR, USD, EUR, RUB, KZT) с пересчётом в одну. Курсы задаются вручную в настройках.
- Логотипы ~70 популярных сервисов: пишешь название, и иконка подставляется сама. Можно выбрать вручную или оставить букву.
- Работает без интернета.

## Как установить на iPhone

1. Открой [irunli.github.io/subs](https://irunli.github.io/subs/) в **Safari**.
2. Нажми «Поделиться» → «На экран «Домой»» → «Добавить».

Приложение откроется на весь экран со своей иконкой, как обычное.

## Где хранятся данные

Только на твоём телефоне, внутри приложения. Никуда не отправляются, сервера нет.

Поэтому:
- если удалить иконку с экрана «Домой», подписки удалятся вместе с ней;
- на другом устройстве их не будет.

Делай резервную копию: настройки (иконка с ползунками) → «Сохранить копию». Файл можно положить в Файлы или iCloud Drive, а потом загрузить обратно кнопкой «Загрузить копию».

## Устройство

Один `index.html` без зависимостей и сборки, плюс `manifest.webmanifest` и `sw.js` для установки и офлайна. Данные лежат в `localStorage`. Логотипы сервисов взяты из [Simple Icons](https://simpleicons.org) (CC0), товарные знаки принадлежат их владельцам. Чтобы сделать свою копию, форкни репозиторий и включи GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
